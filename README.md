# Replication material for
# "GEEPERs: Principal Stratification using Principal Scores and Stacked Estimating Equations"

The paper can be found at https://arxiv.org/abs/2212.10406

It is forthcoming in the Journal of Research on Educational Effectiveness.


Replications will not be exact, mostly because of randomness in the simulation and some of the estimation, and also because of very slight differences (e.g. one additional subject) between the publicly available data and the dataset used in the paper.

Full instructions for replication can be found in README files in the [simulation](project/simulation) and [videoScaffolding](project/videoScaffolding) folders.
